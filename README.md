# Meta Quest 3 Teacher Guide

This folder contains a five-page website for elementary teachers.

## Files

- `index.html`: Introduction to the headset
- `vr-types.html`: Headset, desktop VR, and 360 video
- `controller.html`: Controller functions
- `internet.html`: Internet connection
- `browser.html`: Browser access
- `style.css`: Shared page design

## Publish with GitHub Pages

1. Upload every file to the same GitHub repository.
2. Open the repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the main branch and the root folder.
6. Save the settings.

GitHub will show the website address after the site is ready.
